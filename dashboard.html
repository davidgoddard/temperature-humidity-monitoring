Wi-Fi Temperature Dashboard

Shows readings still retained on the base station. Use the Node archive app to save and browse long-term history.

Not connected

Dashboard and API are served by the base at http://temp.local. Refresh retrieves available measurements over Wi-Fi.

Sensor locations

Add a location or other label for each sensor. Labels are stored on the base station and appear on every browser.

Archive and export

Choose an archive folder in Chrome or Edge, then save the outstanding readings. The base deletes acknowledged readings only after the browser has written the archive file successfully.

Important: direct folder writing is unavailable at ordinary http://temp.local because it is not a secure browser context. Use Download CSV and choose its destination in the browser, or serve this file from localhost/HTTPS to enable Choose archive folder and automatic base acknowledgement.

Reset base station readings

This permanently deletes all readings held by the base station and clears this browser's stored sensor history. Previously downloaded CSV archives are not deleted. Sensors will continue uploading new readings.
